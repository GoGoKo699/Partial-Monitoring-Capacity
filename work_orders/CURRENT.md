# Maintenance checklist

This checklist governs changes to the existing results and their presentation.
The scientific reading route is the [README](../README.md),
[Preskill guide](../research/PRESKILL_READING_MAP.md) and
[model and claim map](../research/MODEL_AND_CLAIMS.md).

1. Read [AGENTS](../AGENTS.md), [WORKSPACE](../WORKSPACE.md), live main and open PRs.
2. Preserve the helper's receiver-only classical message, the joint-register identity,
   unconditional error, average optical signal-energy convention and product scope.
3. Keep proof dependencies and source attribution explicit. A scientific correction
   requires a linked record preserving the original claim and the reason for change.
4. Preserve all protected imports, reference reports, assertions, tolerances,
   authorship, license and the Purpose/contact notice. Package superseded approaches
   in the [archive](../archive/README.md).
5. Review the exact feature-branch diff and run the full commands in
   [VERIFICATION](../VERIFICATION.md), using an exclusive new evidence directory.
6. Inspect the actual PR-head workflow and downloaded evidence; merge only after
   successful checks with the expected head SHA.
7. Verify the actual merged main separately and retain exact revision, run and artifact
   identities, source matches and all comparison differences in the PR receipt.

The [historical work order](../archive/editorial/2026-10-07-pre-release/work_orders/CURRENT.md)
preserves the earlier exploration and learning tasks.
